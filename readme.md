基本需求：自然语言转换为 SQL，以图表的形式呈现给用户

业务逻辑：

1. 准备阶段
   逻辑步骤：获取数据连接 - 获取指定数据库元数据（不允许直接获取数据库连接而操作数据库，只能获取元数据） - 获取数据库及数据表之间关联关系 - 通过 AI 模型语义化各元数据 - 通过 AI 自推断数据库及数据表之间可能的关联关系

关键难点：元数据变更需要及时刷新

2. SQL 生成阶段
   逻辑步骤：用户输入自然语言 - AI 尽可能精准识别用户意图 - 通过准备阶段允许使用的数据连接 - 生成对应的 SQL - 优化并执行 sql - 呈现对应的数据图标

关键难点：精准识别用户意图，经常需要跨库跨表甚至跨 10 个库以上链接查询

3. 安全审计
   逻辑步骤：记录用户的查询及生成全过程 - 黑客攻击

关键难点：历史数据如何存储

技术栈：Next.js + Daisyui

开发代号：Galileo
