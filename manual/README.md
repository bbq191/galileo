## 📖 系统简介

**Galileo** 是一套基于 AI 的自然语言转 SQL 智能查询系统，帮助业务人员通过自然语言快速查询数据，无需编写复杂的 SQL 语句。

### 核心能力

| 能力 | 说明 | 技术实现 |
|------|------|---------|
| 🗣️ **自然语言理解** | 将用户查询意图转换为结构化 SQL | NLP + AI 模型 (意图识别、实体解析、时间解析) |
| 📊 **元数据管理** | 自动采集、同步数据库 Schema | 数据库反射 + 增量同步 + 分表优化 |
| 🧠 **智能推断** | AI 驱动的表关系和业务域推断 | 3 种混合策略 (命名规则 + 向量相似度 + AI 推理) |
| ⚡ **多级缓存** | L1/L2 + 语义缓存 + 防击穿守卫 | 内存 + Redis + 向量相似度 |
| 🔒 **安全审计** | 完整的操作日志和访问控制 | JWT + 双层速率限制 + 审计日志 |
| 📈 **性能监控** | 实时性能指标和慢查询分析 | 性能采集 + 统计分析 + P50/P95/P99 |

### 系统特点

- ✅ **低代码**: 自然语言查询，无需 SQL 知识
- ✅ **智能化**: AI 辅助推断表关系和业务语义
- ✅ **高性能**: 多级缓存 + 连接池 + 查询优化
- ✅ **安全性**: JWT 认证 + 数据加密 + 审计日志
- ✅ **可扩展**: DI 架构 + 模块化设计
- ✅ **易运维**: 完整的监控、日志和告警体系

## 🎯 使用场景

### 1. 业务分析师

**场景**: 需要查询业务数据，但不熟悉 SQL

**使用方式**:
1. 登录系统
2. 输入自然语言查询："查询最近7天的订单总金额"
3. 系统自动生成并执行 SQL
4. 查看结果和可视化图表

### 2. 数据开发工程师

**场景**: 需要快速原型设计和数据探索

**使用方式**:
1. 连接多个数据源
2. 使用自然语言快速探索数据
3. 查看 AI 生成的 SQL，优化后集成到代码
4. 利用审计日志分析查询模式

### 3. 系统管理员

**场景**: 管理数据源和监控系统健康

**使用方式**:
1. 管理数据源连接配置
2. 配置元数据自动同步
3. 监控系统性能和查询统计
4. 查看审计日志和安全事件

## 📊 系统监控

### 监控指标

| 指标类型 | 监控项 | 查看方式 |
|---------|--------|---------|
| 系统健康 | 数据库、Redis、AI 服务连接状态 | `GET /api/health` |
| 性能指标 | P50、P95、P99 响应时间，慢查询 | `GET /api/performance` |
| 缓存统计 | L1/L2 命中率、语义缓存效果 | `GET /api/cache/stats` |
| 审计统计 | 查询总数、成功率、用户活跃度 | `GET /api/audit/stats` |
| AI 成本 | Token 消耗、费用统计 | `GET /api/ai/cost` |
| API 文档 | OpenAPI 3.0 规范 | `GET /api/docs/openapi` |

### 告警机制

- 🚨 错误率超过阈值
- 🚨 慢查询数量异常
- 🚨 缓存命中率过低
- 🚨 速率限制频繁触发
- 🚨 数据库连接异常

详细配置见 [运维手册](./operations.md) 第3节和 [日志系统](./logging.md) 第9节。
